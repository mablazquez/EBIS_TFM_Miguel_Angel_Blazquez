1. Crear y activar el entorno virtual

python3 -m venv .venv
source .venv/bin/actívate

En Windows (PowerShell), activa el entorno con: .venv\Scripts\Activate.ps1


2. Instalar las dependencias

pip install --upgrade pip
pip install -r requirements.txt


3. Configurar las variables de entorno

Abre .env y define tu clave de Google Gemini:

GEMINI_API_KEY=AIzaSy...TuClaveAqui...
LLM_MODEL=gemini-3.8-flash
LOG_LEVEL=INFO
BACKEND_HOST=0.0.0.0
BACKEND_PORT=8000
FRONTEND_PORT=8501
API_BASE_URL=http://localhost:8000
PROMPTS_DIR=data/prompts

4. Conceder permisos a los scripts de inicio

chmod +x scripts/run_backend.sh scripts/run_frontend.sh


5. Ejecutar Test unitarios

$env:PYTHONPATH = "."
pytest


6. Iniciar los servicios (en 2 terminales independientes)

Terminal 1: Arrancar el Backend (FastAPI)
En tu terminal de PowerShell, asegurándote de tener el entorno virtual activo:

$env:PYTHONPATH = "."
uvicorn src.backend.main:app --host 0.0.0.0 --port 8000 --reload

Terminal 2: Arrancar el Frontend (Streamlit)
Abre una segunda ventana de PowerShell, navega a la carpeta del proyecto y ejecuta:

$env:PYTHONPATH = "."
streamlit run src/frontend/app.py --server.port 8501

Se abrirá automáticamente tu navegador en: http://localhost:8501

En la esquina superior derecha verás el indicador verde: Backend Online.
