1. Crear y activar el entorno virtual

python3 -m venv .venv
source .venv/bin/actívate

En Windows (PowerShell), activa el entorno con: .venv\Scripts\Activate.ps1


2. Instalar las dependencias

pip install --upgrade pip
pip install -r requirements.txt


3. Configurar las variables de entorno

Abre .env y define tu clave de Google Gemini:

GEMINI_API_KEY=AIzaSy...TuClaveAqui...
LLM_MODEL=gemini-3.8-flash
LOG_LEVEL=INFO
BACKEND_HOST=0.0.0.0
BACKEND_PORT=8000
FRONTEND_PORT=8501
API_BASE_URL=http://localhost:8000
PROMPTS_DIR=data/prompts

4. Conceder permisos a los scripts de inicio

chmod +x scripts/run_backend.sh scripts/run_frontend.sh


5. Iniciar los servicios (en 2 terminales independientes)
Terminal 1 — Backend (FastAPI + Uvicorn):

./scripts/run_backend.sh

Comando directo alternativo: uvicorn src.backend.main:app --host 0.0.0.0 --port 8000 --reload

Estado: Valida la presencia de las plantillas en data/prompts/ y levanta el servidor en http://localhost:8000.

Documentación interactiva: http://localhost:8000/docs

Terminal 2 — Frontend (Streamlit):

Abre una nueva ventana o pestaña de terminal, activa el entorno virtual y ejecuta:

source .venv/bin/activate
./scripts/run_frontend.sh

Comando directo alternativo: streamlit run src/frontend/app.py --server.port 8501

Interfaz de usuario: Se abrirá automáticamente en tu navegador en http://localhost:8501.
